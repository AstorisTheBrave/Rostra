## what this is

How to run, test, and (later) deploy Rostra. The deploy/Docker pieces land with the runtime plan; the
dev/test commands work today.

## technical map

**install**
- Use a Node.js version matching `engines.node` in `package.json`, with Corepack 0.35.0.
- `corepack enable`
- `pnpm install --frozen-lockfile` - use the single reviewed lockfile and workspace security overrides
- `pnpm prisma:generate` - generate the Prisma client (after any schema change)
- Canonical setup: [CONTRIBUTING.md](../../CONTRIBUTING.md).

**develop**
- `pnpm dev` - runs `apps/gateway/src/cluster.ts` via tsx watch
- `pnpm start:api` - runs the API on `API_PORT` without requiring Discord credentials
- `pnpm start:workers` - runs durable consumers; requires PostgreSQL and `REDIS_URL`
- `pnpm typecheck` - generate the client, then `tsc --noEmit`
- `pnpm lint` / `pnpm lint:fix` - Biome
- `pnpm test` - tests using caller-supplied placeholders; `pnpm test:env` loads local `.env`

**build & run**
- `pnpm build` - generate the client and check TypeScript without emitting a bundle
- `pnpm start` - run `apps/gateway/src/cluster.ts` through tsx
- `pnpm start:api` / `pnpm start:workers` - run the separated API and worker processes
- `pnpm deploy:commands` - register slash commands with Discord

**database**
- `pnpm prisma:migrate` - apply the existing migrations
- Production: Postgres + pgBouncer (transaction mode) recommended at scale
- `pnpm test:integration` - real PostgreSQL/Redis duplicate-delivery and worker-restart proof; CI
  supplies disposable service containers

**current HTTP ownership**
- Gateway `PORT`: compatibility `/health`, shard detail and process metrics.
- API `API_PORT`: detail-free `/health/live` and `/health/ready`, `/votes/topgg`, and authenticated
  `/internal/v1/*` smoke routes. `INTERNAL_API_TOKEN` is required to use internal routes.
- The existing container starts the gateway only. Task 7 owns the multi-process Compose profiles.

## gotchas

- tsup/esbuild needs explicit handling for the `@/*` path alias and `.ts` import extensions - wire this
  when adding the build entry points, or the bundle will fail to resolve imports.
- Commands register globally (one REST push); `/owner` registers to `DEV_GUILD_ID` only.
