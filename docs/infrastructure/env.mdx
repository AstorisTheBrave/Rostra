# Environment variables

Start from [`.env.example`](../../.env.example). Runtime values are validated by `@rostra/config`; do not read environment variables from application packages or commit a real `.env` file.

## Core services

| Variable | Purpose |
| --- | --- |
| `DATABASE_URL` | Required PostgreSQL connection for application data. |
| `DIRECT_URL` | Optional direct connection for migrations when the application URL is pooled. |
| `REDIS_URL` | Redis connection for shared cache, coordination and queue delivery. Use it for multi-process or production deployment. |
| `NODE_ENV`, `LOG_LEVEL` | Runtime mode and structured log threshold. |
| `INTERNAL_API_TOKEN` | Secret used by host-scoped internal API routes. |

## Discord gateway and web login

| Variable | Purpose |
| --- | --- |
| `DISCORD_TOKEN`, `DISCORD_CLIENT_ID` | Gateway credentials and application id. Required by Discord entrypoints. |
| `DISCORD_CLIENT_SECRET` | OAuth client secret for web login. |
| `OWNER_IDS`, `DEV_GUILD_ID` | Configured owner commands and development command registration scope. Owner IDs do not bypass guild authorization. |
| `WEB_PORT`, `WEB_PUBLIC_URL` | Web server port and public origin. |
| `WEB_SESSION_SECRET` | At least 32 characters; signs the opaque web session cookie and state. |
| `WEB_AUTH_MODE` | Production uses `discord`. `fixture` is for automated tests and is rejected in production. |
| `API_PORT`, `API_BASE_URL` | API listener and URL used by the web service. |

## Optional runtime and integrations

| Variable | Purpose |
| --- | --- |
| `REALTIME_ENABLED`, `REALTIME_PORT` | Enable the optional authenticated realtime scaffold. |
| `ACTIVITY_ENABLED`, `ACTIVITY_PORT` | Enable the optional authenticated Activity scaffold. |
| `TOTAL_SHARDS`, `SHARDING_MODE`, `SHARDS_PER_CLUSTER` | Native or optional local process-mode hybrid sharding. Hybrid mode is implemented but not verified against live Discord or at production scale; see [hybrid sharding](hybrid-sharding.mdx). |
| `LAVALINK_NODES`, `LAVALINK_RECONNECT_TRIES`, `LAVALINK_RESUME`, `LAVALINK_REST_TIMEOUT` | Music-node configuration. |
| `TOPGG_TOKEN`, `TOPGG_WEBHOOK_AUTH`, `TOPGG_BOT_ID` | Optional bot-list statistics and vote webhook. |
| `TWITCH_CLIENT_ID`, `TWITCH_CLIENT_SECRET` | Optional credentials for Twitch notification feeds. |
| `AI_API_KEY`, `AI_BASE_URL`, `AI_MODEL` | Neutral configuration for the optional assistant integration. |
| `TRANSLATE_API_KEY`, `TRANSLATE_BASE_URL`, `TRANSLATE_MODEL` | Optional translation-draft tooling configuration. |

Empty optional values are treated as absent. Missing required values fail validation at the owning entrypoint. Redis fallback behavior for selected local features does not make a single-process cache suitable for production queues or multiple application replicas.

For setup, see [CONTRIBUTING.md](../../CONTRIBUTING.md). For Compose environment assignment and secret handling, see the [deployment runbook](../runbooks/deployment.mdx).
