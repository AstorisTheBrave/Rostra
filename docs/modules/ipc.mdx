# Gateway shard IPC

`apps/gateway/src/cluster/ipc.ts` exposes the `Ipc` interface and selects native or hybrid fanout using
`config.sharding.mode`. The native implementation delegates to discord.js `broadcastEval` or executes
locally when no shard manager is attached. The hybrid implementation uses the attached
`discord-hybrid-sharding` `ClusterClient` and falls back to a local call before attachment.

Functions passed to `broadcast` or `fetchValues` are serialized into other shard or cluster contexts.
Keep them self-contained and do not close over local values. Feature code should use the gateway-owned IPC
contract rather than importing or constructing sharding-library clients directly.

The optional hybrid path is implemented but has not been verified against live Discord credentials or
production-scale deployment in the Phase 00 gate. See the [hybrid sharding note](../infrastructure/hybrid-sharding.mdx)
and [capability status](../product/capability-status.mdx).
