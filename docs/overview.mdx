## what this is

Rostra is a single, large Discord bot that replaces 15 separate bots. It does moderation, server
security, auto-moderation, tickets, applications, economy, leveling, giveaways, music, trivia, games,
utilities and more - all in one program that can run across many shards to serve very large numbers of
servers and users. This folder is the map of how that program is built, so anyone (or any new session)
can find their way around without reading the whole codebase.

## technical map

**read first each session:** this file, then `docs/architecture/index.mdx`, then only the
`docs/modules/*.mdx` relevant to the task.

**current state:** the working Discord runtime and feature modules still live in `src/`. Phase 00
has extracted config, logging, database, cache, Discord UI and i18n into shared workspace packages.
Contracts and test helpers have explicit public packages too. Gateway extraction and independently
bootable applications are later tasks. See `docs/sessions/log.mdx` for measured progress.

**where things live**
- `packages/config/src/index.ts` - environment configuration (the only place env is read)
- `packages/{logger,database,cache}/` - shared singletons through public exports
- `packages/discord-ui/` - Components V2 primitives and safe acknowledgement
- `packages/contracts/` - shared job registration type
- `packages/testing/` - isolated fixture directory lifecycle
- `src/services/` - tenant, localization preferences and runtime services pending extraction
- `src/utils/cardFont.ts` - asset-backed rendering helper pending its owning feature move
- `packages/i18n/src/` - translation helper + `locales/en/`
- `src/cluster/` - sharding/IPC abstraction (`ipc.ts`); will hold `cluster.ts` manager entry
- `packages/database/prisma/schema.prisma` - database models
- `docs/superpowers/specs/` and `docs/superpowers/plans/` - the design spec and implementation plans

## gotchas

- **Undercover rule:** nothing anywhere may reference any AI provider/model. The AI feature (built later)
  speaks only as "Rostra". This is a hard invariant - see `AGENTS.md`.
- **UI is Components V2 only** - no legacy Discord embeds anywhere. Build all output via `packages/discord-ui/src/components.ts`.
- **Config is read once** at import and frozen; never read `process.env` outside `packages/config/src/index.ts`.
- **One Prisma client** - only `packages/database/src/index.ts` constructs it (`getPrisma()`).
