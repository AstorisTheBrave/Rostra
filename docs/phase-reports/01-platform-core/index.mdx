## Limits

- Measurements describe one 20-iteration disposable-service workload, not production capacity.
- Baseline and Task 7 runner CPU models differ. Their timing values are shown side by side, not as a
  controlled performance delta.
- The cache path changed from Redis-warm to process-local L1-warm in Task 4, so those warm values are
  not like for like.
- At-least-once delivery and one tested durable effect do not prove exactly-once Discord effects.
- Realtime and Activity remain authenticated scaffolds, disabled by default. No multiplayer, device
  verification, managed ingress, or live Discord deployment is claimed.
