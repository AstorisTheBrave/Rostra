# Phase 01 migration evidence

Phase 01 adds four forward-only migrations after the preserved Phase 00 history:

- `20261019010000_guild_capabilities`
- `20261020120000_cache_revision`
- `20261020130000_transactional_outbox`
- `20261021120000_scheduled_task_claims`

The repository integrity check verifies every historical migration directory and byte snapshot. The
schema keeps earlier rows readable and adds nullable or defaulted state where a rollback image must
continue operating. No destructive down migration is used.

backup when the prior image cannot operate on the new schema. It never means deleting migration
history or running an unreviewed down migration.
