## Phase scope

Phase 00 moves the current Discord gateway into `apps/gateway/`, preserves the module and command registry, introduces public shared packages and adds API, web, worker, realtime and Activity application boundaries. It adds bounded Compose deployment, migration startup checks and correlated service smoke. It does not complete the future module redesign, multiplayer, device verification, multi-instance web sessions or ingress management.
