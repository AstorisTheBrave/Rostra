## What is established today

The bot is the established Rostra product. It includes moderation, server safety, member support, community engagement, music, games and utilities. The exact command inventory is maintained in the gateway; this page intentionally groups capabilities instead of duplicating its command registry.

The current move preserves the recorded command and module inventory. Tests use placeholder credentials, block Discord network access where they load the registry, and never publish commands. A migration or web smoke does not establish a live deployment.

## What remains unproven

- No load test, production-scale capacity result, production OAuth deployment or external security audit is claimed here.
- Optional realtime and Activity tests prove scaffold authentication and image viability only.
- Multi-instance web sessions remain unsupported because sessions are process-local.
- Phase 00 does not establish the later module redesign, multiplayer, device verification or a managed ingress control plane.
