# Managed hosting

There is no currently verified managed-host deployment recipe for Rostra. The old version of this page
named providers, quoted prices, and described deployment steps and capacity that have not been checked
against the current multi-service application. Those recommendations are intentionally withdrawn.

If you self-host, use the repository [README](../../README.md), the supported
[Compose deployment runbook](../runbooks/deployment.mdx), and the
[recovery runbook](../runbooks/recovery.mdx). Rostra does not operate or provision hosting providers,
databases, or ingress on your behalf.
