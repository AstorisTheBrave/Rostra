# Environment variables

The current variables, ownership and deployment notes are maintained in the
[environment reference](../infrastructure/env.mdx). Start from the tracked
[`.env.example`](../../.env.example), replace placeholders locally, and never commit credentials.

Older versions of this page described single-container hosting and unverified hybrid deployment. Use the
current [deployment runbook](../runbooks/deployment.mdx) for Compose configuration and
[hybrid-sharding note](../infrastructure/hybrid-sharding.mdx) for the implemented but not production-verified
optional mode.
