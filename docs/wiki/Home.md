# Rostra

Rostra is a personal open-source Discord app for communities. The bot is the established product; this
repository is moving toward a modular workspace with a typed API, web client and durable workers. The
[repository README](../../README.md) is the quickest product and setup overview. The
[capability status](../product/capability-status.mdx) separates implemented behavior from tested and
verified behavior, and the [roadmap](../product/roadmap.mdx) describes future work.
