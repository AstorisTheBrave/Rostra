# Hosting Rostra

Use the repository [README](../../README.md) for the product and quick start, then follow the supported
[Compose deployment runbook](../runbooks/deployment.mdx). The [environment reference](../infrastructure/env.mdx)
lists configuration values and the [recovery runbook](../runbooks/recovery.mdx) covers backups and rollback.

Older wiki hosting walkthroughs describe the previous single-process bot. Provider integrations, current
prices, resource estimates and production capacity have not been verified for this workspace. The optional
hybrid sharding implementation is available in code but has not been verified against live Discord or at
production scale. See [capability status](../product/capability-status.mdx) before relying on a feature.

Contributors should follow [CONTRIBUTING](../../CONTRIBUTING.md) and the
[architecture map](../architecture/index.mdx).
