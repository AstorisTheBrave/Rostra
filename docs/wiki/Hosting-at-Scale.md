# Hosting at scale

Rostra has no measured production-scale capacity claim. Older versions of this page included provider
pricing, resource estimates and multi-host sharding recipes that were not verified for the current
workspace; those recommendations have been removed.

See the current [deployment runbook](../runbooks/deployment.mdx) for configured per-service resource
limits, the [hybrid-sharding note](../infrastructure/hybrid-sharding.mdx) for implementation status, and
the [capability status](../product/capability-status.mdx) for test and verification boundaries. Measure a
representative workload and validate the chosen topology before production use.
