# Hybrid sharding

Hybrid or cross-host gateway sharding is not supported by the current implementation. The old instructions
on this page described configuration, coordination and deployment behavior that is not available, so they
have been removed. Do not use multiple gateway managers or set `SHARDING_MODE=hybrid` based on this guide.

See the current [capability status](../product/capability-status.mdx),
[roadmap](../product/roadmap.mdx), and [deployment runbook](../runbooks/deployment.mdx).
