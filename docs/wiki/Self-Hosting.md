# Self-hosting Rostra

For the current supported setup, begin with the repository [README](../../README.md) and then follow the
[Compose deployment runbook](../runbooks/deployment.mdx). Review the
[environment reference](../infrastructure/env.mdx) before preparing configuration, and keep credentials
out of source control.

This wiki contains older instructions for a single-process bot. Its provider recommendations, resource
estimates, and setup steps have not been verified for the current multi-service implementation. Do not use
them as a deployment recipe. For recovery, see the [recovery runbook](../runbooks/recovery.mdx).
